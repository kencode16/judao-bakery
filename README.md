# 菊島連連烘

舒壓的麵包甜點連連看，iPhone 和電腦的瀏覽器都能玩。

**👉 開始玩：https://kencode16.github.io/judao-bakery/**

（iPhone 用 Safari 打開，按「分享 → 加入主畫面」，就能像 App 一樣全螢幕玩，也能離線玩。）

## 玩法

- 點兩個一樣的甜點，能用**最多轉兩個彎**的奶油擠花線連起來，就會被吃掉。
- 不計時、沒有失敗；卡住時會自動幫你重新擺盤。
- 5 個地區 × 10 關：法國、台灣、義大利與南歐、英國與美國、日本。每過一關收集一種甜點，共 55 種，圖鑑裡有每一種的口感、搭配飲品和小故事。
- 「菊島」是澎湖的別名，澎湖的縣花是天人菊。

## 製作

- 甜點、飲品、道具插畫全部用程式（Canvas）繪製，沒有使用 AI 生圖或外部圖片。
- 背景音樂：Loyalty Freak Music《POSITIVE ATTITUDE !》專輯，CC0 1.0（公眾領域），出處見 `assets/music/CREDITS.md`。
- 圖鑑內容查證過維基百科、各地觀光與政府網站、新聞和美食媒體等公開資料。
